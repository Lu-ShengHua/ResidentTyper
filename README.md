# 神外小助手

这是一个 Rust + Win32 的最小依赖工具，用于在 Windows 内网环境中通过模拟键盘输入病例模板。窗口会始终置顶，方便在病例系统旁边点击。

当前版本：`v1.4.0`

## 安装

从 GitHub Releases 下载 `ResidentTyper-v1.4.0-windows-x64.zip`，解压后直接运行
`resident_typer_demo.exe`。请保持 `可修改文本` 文件夹与 exe 位于同一目录，模板内容可直接编辑，无需重新编译。

## 运行和调试

```powershell
cargo +stable-x86_64-pc-windows-msvc run
```

构建 exe：

```powershell
.\build_release.ps1
```

构建产物在：

```text
target\release\resident_typer_demo.exe
```

注意：当前电脑的默认 GNU Rust 工具链在中文用户名路径下链接失败，所以脚本固定使用已安装的 MSVC 工具链。

## 修改模板文字

所有可手动修改的文字集中在 `可修改文本` 文件夹中，不需要重新编译：

- `可修改文本/病程模板`：完整病程模板。
- `可修改文本/disease_placeholders.txt`：不同疾病的鉴别诊断、治疗策略等内容。
- `可修改文本/短语集.txt`：流程使用的快捷短语。
- `可修改文本/固定文本.txt`：术前讨论、术后查房等流程中的固定文字。
- `可修改文本/create_courses_config.txt`：批量创建病程的上级医师默认配置。

程序运行时直接读取这些文件。修改后重新点击对应按钮即可使用新内容。

支持的占位符：

- `{SBP}` 收缩压
- `{DBP}` 舒张压
- `{HR}` 心率
- `{RR}` 呼吸
- `{TEMP}` 体温
- `{CONDITIONS}` 根据复选框生成的病情说明

## 修改 UI

主要配置集中在 `src/main.rs` 顶部：

- `BUTTONS`：按钮名称和模板/内置流程映射
- 控件 ID：新增按钮或复选框时改这里
- `render_template`：模板替换和复选框联动逻辑
- `random_vitals`：生命体征随机范围

## 使用方式

1. 按需勾选高血压、糖尿病、心率快、病重。
2. 点击模板按钮。
3. 如果没有勾选“取消切换光标提醒”，确认弹窗后在 3 秒内把光标切换到病例系统输入框。
4. 程序开始模拟键盘输入。
5. 熟悉流程后可以勾选“取消切换光标提醒”，点击模板按钮后直接倒计时 3 秒开始输入。
6. 需要中止时按 `右 Ctrl + 右 Alt`，也可以点击“停止输入 右Ctrl+右Alt”。
7. 最小化后程序进入系统托盘；双击托盘图标恢复，右键可切换任务栏显示、吸附、主题、开机启动，并可打开设置页选择病历系统和医嘱系统启动文件。
